# AçıklandıMı Telegram Takip Botu

Malatya Adliyesi duyurularını GitHub Actions ile her 5 dakikada bir kontrol eder.
Yeni duyuru eklendiğinde ve İKM mülakat sonuçları açıklandığında Telegram'a mesaj atar.

Gerekli secret'lar (Settings → Secrets and variables → Actions):
- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_CHAT_ID`
